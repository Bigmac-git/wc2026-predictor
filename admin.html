Setup Checklist
GitHub Repo Setup Instructions
  1. Create a public GitHub repository (e.g. wc2026-predictor)
  2. Create a folder called submissions/ in the repo (add a .gitkeep file inside)
  3. Upload all 3 HTML files + shared.js to the repo root
  4. Go to github.com/settings/tokens → Generate new token → select repo scope
  5. Paste the token into CONFIG.GITHUB_TOKEN in shared.js
  6. Sign up at api-football.com → free account → copy your API key into CONFIG.API_FOOTBALL_KEY
  7. Enable GitHub Pages on the repo (Settings → Pages → Deploy from branch → main) to get a public URL
  8. Share the predict.html URL with all players!
